# 0.9.7~alpha — 2026-10-29

Tag: `v0.9.7-alpha`

Encrypted config backup/restore + SSO service indicators. Device-proven
live on Pixel 6 (backup → `pm clear` → restore → services back).

## Backup & restore (new, Settings → Danger Zone)
- "Back up config": password-encrypted envelope (`seekarr-backup.enc`,
  AES-256-GCM + PBKDF2-SHA256 200k, `cryptography` package) via the
  system save dialog (defaults to Downloads). Versioned envelope
  (`v:1`) for forward compatibility.
- "Restore config": file picker → password dialog with inline
  wrong-password retry (fail-closed, state untouched) → writes prefs +
  secure-store entries, forces onboarding-complete, wipes OIDC session
  caches, reloads provider state, prompts re-login.
- Backed-up scope: all service URLs + API keys/passwords + OIDC
  issuer/client + prefs. OIDC tokens deliberately EXCLUDED (session
  never survives a restore — re-login required).
- File picker note: `FileType.custom` extension filters throw
  `PlatformException(Unsupported filter)` on this Android target, so
  restore uses `FileType.any` + envelope validation. Same pattern in
  qBittorrent torrent import may be affected.

## SSO service connections (new, Settings → Authentication)
- Per-service dots: green = live service token cached for the host,
  orange = SSO identity exists but no service token yet,
  red = no SSO identity. Screen is scrollable now.

## Fixes
- `isServiceConfigured` counts URL-only services in OIDC/ArrStack mode
  (previously the dashboard hid Sonarr/Radarr entirely without API
  keys, blocking the lazy-exchange path).
- `kAppVersion` synced (was one release behind pubspec).
