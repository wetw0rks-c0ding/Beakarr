# 0.9.11~alpha — 2026-10-30

Tag: `v0.9.11-alpha`

Grab sheet renders above the floating nav bar; tile navigation
verified end to end on device.

## Fixes
- Prowlarr grab sheet (`_showGrabDialog`) used a bare
  `showModalBottomSheet` inside the shell navigator, so the sheet
  rendered UNDER the floating nav bar and the Grab button hid behind
  it. Now uses `SheetUtils.showSeekarrModalSheet` (root navigator),
  with a new optional `shape` passthrough on the helper.
- Regression test: tapping a result card opens the grab sheet with
  Grab/Cancel (`prowlarr_search_flow_test.dart`).
- New `service_status_grid_nav_test.dart`: real grid + real GoRouter,
  tile tap navigates to the service route. Device taps confirmed
  working too (`DIAG-TAPTILE` probe, since removed) — earlier
  no-navigation reports were ghost taps on empty/loading states,
  not a router bug. The `GoRouter.of` one-liner is kept (harmless).
