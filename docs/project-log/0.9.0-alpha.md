# 0.9.0~alpha — 2026-10-27

Tag: `v0.9.0-alpha` (commit `12c8533`)

First fork release. Prowlarr + Bazarr join the service lineup.

## Prowlarr
- Indexers list with enable/disable, release search, grab-to-download.
- Global search fan-out includes Prowlarr releases with sort control
  (seeds/size/age) and green seeder counts.
- Test-connection button; iOS ATS exception for self-hosted hosts.

## Bazarr
- Series/movies/wanted/providers tabs aligned to the real Bazarr 1.6.2
  API shapes (enveloped `{data,total}`, `sonarrSeriesId`/`radarrId`,
  `seriesid[]` episodes query, PATCH/DELETE subtitle endpoints with
  string flags). Download-best subtitle semantics (no per-provider
  search endpoint exists server-side).

## Release infrastructure
- App version row in Settings → About (`0.9.0-alpha`).
- In-app GitHub link + pubspec metadata point at the fork.
- Signed release APK + xcross-built unsigned IPA (TrollStore-tested).
- Dedicated release keystore (`~/.config/seekarr/`, gitignored).
