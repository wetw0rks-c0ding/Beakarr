## Test Connection via OIDC (device-proven)
- `service_connection_provider.dart` `_testServiceConnection` +
  `_checkService` built a bare `ApiClient` (API key only), so empty-key
  ArrStack configs always 401'd instead of lazy-exchanging. Now reuses
  the OIDC-capable wiring (serviceKey + session + issuer + clientId)
  when the service is sonarr/radarr/prowlarr, an issuer is set, and the
  key is empty or ArrStack mode. API-key configs byte-identical;
  interceptor untouched.
- Proven: Sonarr + Prowlarr settings show green **Connected** with
  empty API key, live system/status JSON in logcat (pre-fix same screens
  showed `Connection failed`).
