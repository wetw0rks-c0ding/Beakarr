# 0.9.20-alpha — 2026-11-01

Tag: `v0.9.20-alpha`

Wizarr phase 2: guest-invite creation from the app, device-proven
against live bertha Wizarr v3.

## Invite creation (new, gated mutating path)

- Invitations tab gains a "New invite" action opening a full-screen
  form: server multi-select chips, library chips scoped to chosen
  servers, expiry segments (Never/1/7/30 days), unlimited toggle
  (disables duration, sends `"unlimited"`), duration days, three
  permission switches.
- Last-used snapshot persisted per device (non-secret prefs);
  first run falls back to all servers, no library restriction,
  7-day expiry, unlimited off, 30-day duration, all permissions on.
- Confirm line states the grant explicitly; success shows the
  absolute share link with copy, refreshes the list, then closes.
- The client allowlist gains exactly one mutating key
  (`Invitation.create` → literal `POST /api/invitations`); every
  other non-list call still throws before any network I/O.
- Deselecting every server disables Create (no silent all-server
  grants); saved IDs are intersected with the loaded server list;
  prefs-save failures can't flip a success into an error report;
  non-JSON/HTML and 4xx surfaces as error states, never empty lists.

## Device proof (Pixel 6, live bertha:5691)

- Form renders live servers/libraries; created a real 1-day-expiry
  invite → success view with absolute link + copy; new row appears
  with correct chips (tile count 2 → 3).
- Deselect-all verified on touch: Create disabled, no POST possible.
- Proof invite is 1-day self-cleaning; codes never enter the repo.

## Review / tests

- Subagent-driven (beam-free): per-task implement + review, fix
  loops closed with scoped re-reviews, clean final review.
- CodeRabbit gates: field-name fixtures pinned to live swagger;
  unconfigured error kept inside `AsyncValueWidget`; no silent
  all-server grants; prefs-failure isolation; stale-ID pruning.
- OCR pre-pass triaged per commit.
- Full suite: 1243+ tests green; `flutter analyze` clean
  (whole-tree `--fatal-infos` during release).
