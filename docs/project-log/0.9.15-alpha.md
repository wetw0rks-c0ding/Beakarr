# 0.9.15-alpha — 2026-10-31

Tag: `v0.9.15-alpha`

NZBGet joins the fleet: full monitor + control, device-proven on Pixel 6
against live NZBGet 26.3 (yakubscave:6789).

## NZBGet (new service)
- Settings: Server URL + required Username/Password (credential form),
  Test Connection runs `version` then `status` (reachability + scope proof
  in one check) and auto-saves on green.
- Dashboard tile: ONLINE + version + queue count ("N downloads").
- NZBGet screen: Queue/History segmented control, status strip, queue tiles
  (category chip, status pill, MB remaining/total, progress, health %,
  per-item pause/resume/delete), history tiles (outcome pills, size,
  relative time), add-by-URL sheet (category, priority, add-paused),
  multi-select bar with confirm dialog, 5 s polling of status+queue only.
- Stateless HTTP Basic transport (`BasicAuth` + `ApiClient`, no session);
  `-32602` arity fallback for pre-v17/v16 `append` servers.

## Device proof (Pixel 6, live server)
- Test Connection green + `settings saved` snackbar; tile ONLINE.
- Queue rendered live items with server-matching metadata; history tab +
  filters + empty state matched an empty server history.
- Per-item Pause → server `PAUSED`, Resume → server `DOWNLOADING`,
  both verified via direct RPC reads. Note: NZBGet applies pause
  asynchronously — an immediate re-read can still show the old status.
- Queue left running (resumed after the test); nothing deleted, nothing
  added.
