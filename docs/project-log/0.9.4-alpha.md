# 0.9.4~alpha — 2026-10-28

Tag: `v0.9.4-alpha` (commit `0b05e0b`)

In-app updater.

## Updater
- Tapping Settings → Version checks the fork's releases API (drafts
  skipped, prereleases included) and compares against the in-app version.
- Android: downloads the `-android.apk` asset with progress and fires the
  system installer (FileProvider + platform channel, install permission).
- iOS: "Jailbroken" settings toggle — on: downloads the IPA and hands it
  to TrollStore via share sheet (iPad-safe origin); off: opens the
  releases page in the browser.
- Version-compare + release-pick unit tests; Dio timeouts; download
  dialogs dismiss via their own context (no router interference).

## Changes since 0.9.3
- `lib/core/updater/`, Version row action, Jailbroken toggle,
  Android manifest permission + FileProvider.
