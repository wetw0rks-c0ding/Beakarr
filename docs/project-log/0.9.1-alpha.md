# 0.9.1~alpha — 2026-10-28

Tag: `v0.9.1-alpha` (commit `107b596`)

OIDC app-level login (Authentik), verified end-to-end on Pixel 6.

## Auth
- `OidcSessionService`: Authentik issuer discovery, PKCE (S256) flow,
  tokens in secure storage.
- In-app WebView login screen (works in any browser situation); loopback
  redirect (`127.0.0.1:8765`) with custom-scheme deep link as fallback.
- Global Dio interceptor injects `Bearer` when a session is active, with
  single 401 refresh-and-retry.
- Settings → Authentication screen (issuer URL, client ID, Login/Logout,
  session status). GoRouter ignores custom-scheme locations.
- Fixes along the way: trailing-slash discovery 404, dead Auth screen
  route, TextField controller focus loss, overlapping settings saves.

## Changes since 0.9.0
- `lib/features/auth/`, `lib/core/interceptor/`,
  `oidcIssuer`/`oidcClientId` settings, Android deep link + iOS URL scheme.
