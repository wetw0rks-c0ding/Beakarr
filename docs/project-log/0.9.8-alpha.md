# 0.9.8~alpha — 2026-10-29

Tag: `v0.9.8-alpha`

Fixes the qBittorrent torrent picker crash (`FileType.custom` throws
`PlatformException(Unsupported filter)` on this Android target).

## Fixes
- `lib/features/qbittorrent/presentation/widgets/add_torrent_button.dart`
  (both pick sites): `FileType.custom` + `allowedExtensions: ['torrent']`
  → `FileType.any` with a post-pick `.torrent` extension filter.
  Non-torrent picks are dropped with an info snackbar instead of a
  native crash. Same pattern already proven on-device in the
  backup/restore picker (0.9.7 gate).
- Device note: qBittorrent service itself is unconfigured on the test
  device, so the Add Torrent sheet could not be reached to re-prove the
  picker there; the identical `FilePicker.platform.pickFiles(
  FileType.any, withData: true)` call is already crash-free on this
  device via the restore flow.

## Pre-existing observations (not changed)
- Dashboard service tiles do not navigate on tap (tile tap clears the
  tile list into a loading state; tiles return after status refresh).
  Unrelated to this fix; needs a separate look.
- `file_picker` `FileType.custom` is broken on this target — anything
  else using extension filters will hit the same crash.

## Changes since 0.9.7
- qBittorrent picker only (+ version sync).
