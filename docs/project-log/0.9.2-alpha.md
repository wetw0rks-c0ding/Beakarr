# 0.9.2~alpha — 2026-10-28

Tag: `v0.9.2-alpha` (commit `fed4104`)

Navidrome (Subsonic) service, verified against a live 1300+ artist library.

## Navidrome
- `SubsonicAuth` (per-request salt + `md5(password+salt)` token).
- Artists/Albums library with working search; artist detail page with
  per-album expandable track lists.
- Authenticated cover art (`getCoverArt`) in lists and artist page, with
  URL caching so scrolling doesn't refetch.
- Connection checks honor Subsonic `status: failed` bodies (HTTP 200 lies);
  required-credential onboarding and settings validation.

## Changes since 0.9.1
- `lib/features/navidrome/`, `SubsonicAuth`, Navidrome settings/onboarding.
