# 0.9.6~alpha — 2026-10-29

Tag: `v0.9.6-alpha`

ArrStack single-tile OIDC: one Authentik login covers Sonarr + Radarr.
Device-proven live on Pixel 6 against both forks.

## Auth
- ArrStack provider (`iss .../o/arrstack/`, `aud=arrstack`) replaces the
  per-service pilot issuers. One PKCE login, fleet-wide token.
- "Use ArrStack preset" button wipes old pairs via the proper path;
  Sonarr login row hides in single-tile mode (covered by main login).
- Lazy 401 → exchange → retry per host (Sonarr pilot + Radarr
  second-service proof, both 200 + cached live on device).
- `RefreshOutcome` (refreshed/rejected/transient): network blips never
  clear the session; refreshes are joined so concurrent 401s share one
  token call; exchange-after-refresh ordering retries with fresh tokens.
- Bearer use origin-scoped per host; raw Authentik tokens never sent to
  *arr hosts; shared-identity clear drops the fleet cache as well.
- Trailing-slash host URLs canonicalized (Radarr stored URL produced
  `//api/...` → empty 401 before routing).

## Wiring
- Sonarr + Radarr clients carry the interceptor (`serviceKey`-gated,
  Radarr active only in ArrStack mode). OIDC-only configs allowed;
  Radarr still requires an API key outside ArrStack mode.

## Changes since 0.9.5
- `lib/core/interceptor/oidc_auth_interceptor.dart` lazy exchange,
  refresh outcomes, origin scoping, canonical host key.
- `lib/features/auth/data/oidc_session_service.dart` per-service store,
  ArrStack mode, joined refreshes.
