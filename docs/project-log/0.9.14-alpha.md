# 0.9.14-alpha — 2026-10-31

Tag: `v0.9.14-alpha`

SoulSync settings stop losing the profile; Test Connection now saves
what it proves. Plus the Beakarr application-id cutover. All
device-proven on Pixel 6 unless stated.

## The "disappearing profile" (device-proven fixed)
- The profile dropdown list is transient screen state — rebuilt only on
  tapping Load profiles — so reopening settings showed no picker and
  the saved value's fate was unclear. Settings now **auto-load
  profiles on open** when URL + key (or proxy cookie) exist, pre-select
  the saved value, and show a `Saved profile: X` hint when the list
  can't load. Screenshot-verified: Admin pre-selected, zero taps.
- Regression test: saved hint renders with an unreachable host (no
  crash, no dropdown).

## Test Connection auto-save (device-proven)
- A green test used to imply "saved" while persisting nothing — backing
  out lost everything (the S23 trap). A successful Test Connection now
  persists the tested values via the same path as Save (without
  popping), with a `… connected — settings saved` snackbar.
  Screenshot-verified on-device.
- Failure path guarded by test: a failed test never touches stored
  settings.

## CodeRabbit gate findings, fixed (re-review: 0 findings)
- Stale saved id (deleted server-side) no longer nulled in state:
  state keeps it so Save/Test never wipe the stored value without an
  explicit re-pick; the dropdown renders a null-safe value (hint)
  instead of throwing. Pure helpers `resolveSoulSyncProfileSelection`
  + `soulSyncDropdownValue` unit-tested (7 cases).
- Loader discards responses when URL/key/cookie changed mid-load.
- Test success rebuilds the snapshot from live fields instead of
  saving the pre-test snapshot (no clobber of mid-test edits).
- API-key validator passes cookie-only SoulSync setups (stored proxy
  cookie, empty key) so their green tests auto-save.

## Beakarr application-id cutover
- Android applicationId/namespace/`MainActivity` package and iOS
  bundle are now `labs.wetw0rks.beakarr`. Old and new apps install
  side-by-side; migrate via backup/restore (password-encrypted export
  in Danger Zone).
