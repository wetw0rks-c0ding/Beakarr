# 0.9.5~alpha — 2026-10-28

Tag: `v0.9.5-alpha` (commit `b1171d9`)

SoulSync Discover rework + qBittorrent fixes.

## SoulSync
- Discover tab rebuilt to mirror the server UI: Discovery Pool (paged,
  "Load more"), Similar Artists, Recent Releases, bubble snapshots —
  with cover art and durations on every row via one shared tile.
- Downloads tab absorbs the download-request composer
  (`POST /api/v1/request`); downloads list refreshes after requesting
  and supports pull-to-refresh.
- Real field mapping from the SoulSync API docs (`track_name`,
  paged envelopes, snapshot structures).

## qBittorrent
- Selection bar scrolls so Delete stays reachable on narrow screens
  (regression-tested at 360px).
- Torrent tile red-screen (duplicate radius) fixed — debug-only crash.

## Changes since 0.9.4
- `lib/features/soulsync/` Discover/Downloads rework, qbit selection
  bar + tile fixes.
