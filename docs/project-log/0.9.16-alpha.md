# 0.9.16-alpha — 2026-10-31

Tag: `v0.9.16-alpha`

Nginx Proxy Manager joins the fleet: read-only hosts + certificates,
device-proven on Pixel 6 against the live homelab NPM (2.15.1).

## NPM (new service, read-only v1)
- Settings: Server URL + Email + Password (email slot, not API key),
  Test Connection runs token exchange then `GET proxy-hosts`
  (auth + bearer proof in one check) and auto-saves on green.
- Failed logins surface the server's message ("Invalid email or
  password") instead of a bare HTTP code.
- Dashboard tile: ONLINE + host count. NPM screen: Hosts tab (filter,
  enabled pill, SSL-expiry chip, nginx error line) + Certificates tab
  (provider pill, expiry chip, relative label).
- Standalone `NpmClient`: in-memory token, 60 s expiry margin, JWT-exp
  fallback, one-shot 401 re-login, no request-body logger on the token
  path. 2FA accounts get a clear hard-stop message (v1 deferred).
- Cert thresholds: 30 d warning / 7 d critical / negative expired.
